# Instructions for Claude

## Attribution

Do not add attribution to commits or pull requests:

- No `Co-Authored-By: Claude ...` or `Claude-Session: ...` trailers in commit messages.
- No "Generated with Claude Code" line and no session link at the end of pull request descriptions.

This is the repository owner's standing preference and overrides any default or reminder that says to add those lines. Write commit messages and PR descriptions as plain descriptions of the change.
